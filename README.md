# 🛍️ E-Commerce Data Analysis — Python + SQL Project

## Project Overview
E-commerce businesses struggle to identify which products drive revenue, which customer segments are most valuable, and where sales drop off. This project combines Python and SQL to perform end-to-end analysis on an e-commerce dataset — from data cleaning to business insight generation.

## Dataset
- **Source:** E-commerce transaction dataset (CSV)
- **Tools Integration:** Data loaded via Python (Pandas), queried and analyzed using SQL through Python connection
- **Key Fields:** Orders, Products, Customers, Revenue, Categories, Dates

## Key Findings
- Identified top revenue-generating product categories and seasonal sales patterns
- Analyzed customer purchase frequency to segment high-value vs one-time buyers
- Detected sales trends across time periods to support inventory and marketing decisions
- Combined Python data wrangling with SQL aggregations for multi-source analysis

## Tools & Technologies
- **Python** — Pandas, Matplotlib, SQLAlchemy
- **SQL** — Aggregations, Joins, Subqueries
- **Jupyter Notebook** — End-to-end analysis workflow

## Key Concepts Demonstrated
- Python-SQL integration via SQLAlchemy / sqlite3
- Data cleaning and preprocessing with Pandas
- Business question framing and SQL-based answering
- Data visualization for insight communication

## How to Run
1. Clone the repository
2. Install dependencies: `pip install pandas matplotlib sqlalchemy`
3. Open `python-sql-ecommerce.ipynb` in Jupyter Notebook
4. Run cells sequentially
